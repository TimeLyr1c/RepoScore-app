# 全屏阅读与自动单双页

## Status
Accepted — 2026-10-19

## Context

iPad 横屏双页阅读时，页面四周和两页之间有明显空隙：页组容器有 8pt 内边距和 8pt 页间距；每页在各自半屏内居中，导致中缝和外侧出现空白；PDFKit 默认显示分页灰边和阴影；导航栏和底部翻页栏又占去屏幕高度。默认单页模式也让横屏只显示一页。

## Decision

阅读页始终按全屏布局，忽略安全区域。页组容器按各页实际比例（统一高度）计算总宽高，整体等比适配屏幕并居中，页面在中缝处紧贴；关闭 PDFView 的分页边距和阴影。导航栏、状态栏和翻页栏浮在页面上方，打开时显示，边缘点击或滑动翻页后隐藏，点按中间区域切换。新增“自动”布局并设为默认：横屏双页、竖屏单页；单页和双页仍可固定选择。

## Reasons

横屏 iPad 的宽高比（约 1.43）接近两张竖版 A4 并排（约 1.41），去掉界面占用后两页几乎可以铺满屏幕。按比例拼接比让 PDFKit 在两个半屏里各自居中更紧凑，也继续沿用 ADR 0004 的显式页组。

## Consequences

- 页面比例与屏幕不同时仍会留下少量空白，背景色使用系统背景色，浅色模式下与纸张颜色接近。
- 两页高度不同时按较高页统一缩放，较矮页面按原比例显示。
- 阅读时返回需要先点按中间显示导航栏。
- 不裁切 PDF 自身的白边；扫描乐谱自带的大白边仍会显示。如有需要可后续评估“裁切白边”选项。

## Alternatives considered

保留导航栏、只去掉边距：横屏仍损失约 15% 高度。使用 PDFKit twoUp 加 displaysAsBook：无法精确控制单页占位和交互，见 ADR 0004。
