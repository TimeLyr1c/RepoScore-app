# RepoScore — Roadmap

## 当前范围与实施计划

当前工作：完成文件夹组织和双页阅读，验证与 M1 的兼容性；M0/M1 的结果保留在下方。

当前里程碑：M2 功能实现和模拟器验证完成；M1/M2 真机验收仍待完成。

M2 实施计划：索引升级为 version 2（文件夹 parentID、乐谱 folderID），迁移前保留 version 1 索引副本；新增按层级浏览、文件夹创建/重命名和乐谱移动。阅读以物理页码为位置锚点，显式计算单/双页配对，加入边缘点击/滑动及旋转位置保持。先验证迁移、层级、原子失败和页组规则，再进行 iPad 模拟器 UI 测试及 Debug/Release 构建，记录真机未验收项。删除、标签、演出功能和持久阅读进度不在本轮范围。

M1 实施计划：新增乐谱记录及本地 repository（独立 PDF + 原子 JSON 索引）、曲库状态与系统文件选择器、PDFKit 单页阅读；添加导入/恢复/失败行为测试及界面验证，更新架构和运行说明。只处理根目录中的单份 PDF，不提前实现文件夹、双页或演出功能。

- 最终构建仅有未使用 AppIntents 的元数据跳过警告；最终测试没有 SwiftUI 状态发布警告。开发中两处编译错误（override、toolbar disabled 位置）已修正。
